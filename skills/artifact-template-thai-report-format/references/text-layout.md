# การจัดข้อความและการตัดบรรทัด

ข้อกำหนดนี้เป็นค่าเริ่มต้นถาวรเพิ่มเติม ใช้ทับการจัดแนวเนื้อหาและตารางแบบเดิม คงขนาดกระดาษ ระยะขอบ ฟอนต์ ขนาดอักษร การเยื้อง ระยะย่อหน้า ค่าสารบัญ และข้อกำหนดอื่นไว้ เว้นแต่ผู้ใช้ระบุเปลี่ยน

- เนื้อหาและข้อความในตารางทุกเซลล์ใช้ Align Left ห้าม Distributed, Thai Distributed หรือการยืดช่องไฟให้เต็มบรรทัด
- Character Spacing ของข้อความทั้งหมด: Normal, Scale 100%, Spacing 0 pt, Position Normal ไม่ใช้ Fit text/การบีบตัวอักษร รักษาตัวยกและตัวห้อยที่มีความหมาย เช่น เลขเชิงอรรถ
- หัวข้อและคำบรรยายภาพจัดแนวตามแม่แบบ คำบรรยายตาราง สารบัญ หัว–ท้ายกระดาษคงการจัดแนวเดิม หากเอกสารนำเข้าใช้ direct formatting โดยไม่มี style ให้ระบุบทบาทและผูก style ของหัวข้อ/คำบรรยายก่อนใช้สคริปต์ เพื่อไม่ให้ถูกมองเป็นเนื้อหาปกติ
- ให้ Word ตัดบรรทัดอัตโนมัติ ห้ามเพิ่มช่องว่าง แท็บ Enter หรือ Shift+Enter หรืออักขระแฝงเพื่อดันข้อความให้จัดแนว ตรวจตัวแบ่งบรรทัดและช่องว่างที่มีอยู่ ลบเฉพาะสิ่งที่ใช้บังคับการจัดหน้าโดยไม่ทำให้คำติดกันหรือเสียความหมาย รักษา paragraph/list/page breaks ที่มีความหมาย ไม่ล้างตัวแบ่งทั้งหมดโดยอัตโนมัติ

## การไหลของข้อความภาษาไทย

ให้ข้อความไทยในเนื้อหาและตารางไหลต่อเนื่องจนใกล้ขอบขวาของพื้นที่ข้อความหรือขอบเซลล์ โดยตัดบรรทัดระหว่างคำอย่างเหมาะสม ไม่ย้ายวลีทั้งช่วงลงบรรทัดใหม่เมื่อคำต้นของวลีนั้นยังพอดีกับพื้นที่ที่เหลือ คง Align Left, Scale 100%, Spacing 0 pt และ Position Normal ไม่ยืดช่องไฟให้เต็มบรรทัด ขอบขวาไม่จำเป็นต้องเสมอกัน และบรรทัดสุดท้ายของย่อหน้าสั้นได้

ห้ามแทรก Enter หรือ Shift+Enter เพื่อบังคับตัดบรรทัด รักษาการแบ่งย่อหน้าที่มีความหมาย หากพบช่องว่างท้ายบรรทัดมากผิดปกติ ให้ตรวจตัวแบ่งบรรทัดที่ใช้จัดหน้า อักขระที่ห้ามตัดบรรทัด ภาษาของข้อความ ระยะเยื้อง และพื้นที่จริงภายในเซลล์ แก้เฉพาะสิ่งที่ทำให้ข้อความถูกยกเป็นวลีโดยไม่จำเป็น ไม่แทรกช่องว่างหรืออักขระแฝงเพื่อบังคับจุดตัดคำ และไม่แก้ด้วยการอนุญาตให้ตัดกลางคำ

หลังจัดหน้าและอัปเดตฟิลด์ ให้ตรวจผลใน Microsoft Word และภาพเรนเดอร์จาก Word ทั้งย่อหน้าปกติและตาราง: ข้อความใช้พื้นที่บรรทัดได้เหมาะสม ไม่มีวลีถูกย้ายทั้งช่วงเมื่อยังใส่คำได้ ไม่มีคำแตกกลางคำ ช่องไฟปกติ และข้อความไม่ล้นหรือถูกตัด หากพบปัญหาให้แก้และตรวจใน Word อีกครั้งก่อนส่งไฟล์

## ตาราง

1. เปิด Wrap text ของเซลล์ ปิด Fit text และปิด Allow Latin text to wrap in the middle of a word ของย่อหน้า ให้ภาษาอังกฤษตัดระหว่างคำ
2. ใช้ภาษาไทยกับข้อความไทยเพื่อให้ Word ใช้การตัดคำตามภาษา ตรวจขอบเขตคำจากภาพจริง เช่น “เครือข่าย” และ “ทำงาน” ต้องไม่แตกกลางคำ ไม่มีสวิตช์ OOXML เดียวที่รับประกันการตัดคำไทยถูกต้องทั้งหมด
3. ให้แถวขยายตามเนื้อหา ไม่ใช้ความสูง Exactly ที่ตัดข้อความ กำหนด Auto หรือ At least และตรวจทั้งเซลล์ที่รวมกันและตารางข้ามหน้า
4. ถ้าคอลัมน์แคบจนคำไม่พอดี ให้เพิ่มความกว้างคอลัมน์นั้นและปรับคอลัมน์อื่นตามเนื้อหา โดยความกว้างรวมต้องไม่เกินพื้นที่ระหว่างขอบกระดาษใน section นั้น ห้ามแก้ด้วยการยืด/บีบตัวอักษร แทรกช่องว่าง หรือบังคับขึ้นบรรทัดกลางคำ

## การตรวจสะกดเฉพาะเอกสาร

ใช้ Do not check spelling or grammar กับข้อความทั้งหมด รวมตาราง หัว–ท้ายกระดาษ เชิงอรรถ สารบัญ และข้อความที่เพิ่มหลังอัปเดตฟิลด์ ปิดการแสดงเส้นหยักแดง/น้ำเงินเฉพาะเอกสาร ห้ามเปลี่ยน Word Options หรือค่าผู้ใช้ที่มีผลต่อเอกสารอื่น

## สคริปต์และการตรวจส่งมอบ

`new_report.py` ใช้ `apply_text_layout.py` กับสำเนาเริ่มต้นโดยอัตโนมัติ หลังใส่เนื้อหาและอัปเดตฟิลด์แล้ว ให้ใช้กับสำเนาสุดท้ายอีกครั้ง:

```text
python scripts/apply_text_layout.py --input input.docx --output final.docx
```

สคริปต์ตั้ง `w:jc=left` สำหรับเนื้อหาและเซลล์, `w:wordWrap=1` สำหรับไม่ตัดคำ Latin กลางคำ, `w:noWrap=0`, `w:tcFitText=0`, ความสูงแถว atLeast, `w:w=100`, `w:spacing=0`, `w:position=0`, `w:noProof=1` และซ่อน spelling/grammar errors ใน settings.xml ของเอกสาร สคริปต์ไม่เปลี่ยนข้อความ ไม่ตัดคำไทยเอง และไม่ปรับความกว้างคอลัมน์ตามความหมายแทนผู้จัดเอกสาร

อัปเดตเลขหน้าหลังจัดหน้า แล้วเรนเดอร์สำเนาสุดท้าย ตรวจทุกหน้า: ตัวอักษรระยะห่างปกติ คำไทย/อังกฤษตัดตรงขอบเขตคำ ข้อความไม่ล้นเซลล์ ไม่ถูกตัด แถวไม่ซ้อน และตารางอยู่ในขอบกระดาษ หากพบปัญหาให้แก้ความกว้างคอลัมน์/โครงสร้างและเรนเดอร์ใหม่ก่อนส่ง ห้ามยืนยันว่าการตัดคำถูกต้องจาก XML เพียงอย่างเดียว

หมายเหตุสำหรับผู้พัฒนาสคริปต์: OOXML `wordWrap=1` หมายถึงตัดระดับคำ ส่วน `wordWrap=0` อนุญาตตัดระดับอักขระ อย่าสับสนกับชื่อ checkbox หรือค่า Word COM ดู [Microsoft WordprocessingML WordWrap](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.wordwrap?view=openxml-3.0.1)
